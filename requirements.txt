# Dipendenze di ESECUZIONE degli strumenti del DM — scripts/
#
# ⚠️ Leggi prima ADR-0037 (`plans/adr/ADR-0037-stdlib-only-e-le-sue-eccezioni.md`).
# La regola del repo resta **stdlib-only**, e questo file non la annulla: elenca
# le tre eccezioni che esistono davvero, con chi le usa e cosa succede senza.
# Il motivo della regola non è estetico — gli strumenti girano sul portatile del
# DM la sera della sessione, spesso senza rete, e un `pip install` che fallisce
# alle 20:45 è un booklet che non si stampa.
#
# Misurato sul repo il 2026-09-21 (`ast` su tutti i `scripts/**/*.py`): fuori
# dalla libreria standard ci sono **queste tre e nient'altro**. `bpy` e
# `mathutils` non sono qui perché non si installano con pip: sono il Python
# interno di Blender, e `scripts/blender/` gira dentro Blender.
#
# ⚠️ `converters/` NON è coperto da questo file. È un mondo a parte (motori PDF,
# OCR, modelli), dichiarato tale in AGENTS.md, e ha le sue dipendenze.
#
#   installa tutto:   pip install -r requirements.txt
#   per sviluppare:   pip install -r requirements-dev.txt

# export_booklet_typst.py, misura_stampa.py, varianti_stampa.py e i validatori

# restano a Chromium. Versione FISSATA, non un pavimento (ADR-0020 §3): la
# 0.15.2 incorpora il compilatore 0.15.1, misurato identico alla CLI su 19
